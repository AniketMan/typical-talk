# Typical Talk

Async video messaging, reimagined. Web demo of the Typical Talk iOS app concept.

- **Talks** — one-to-one and group conversations, newest first, large playable previews
- **Thread** — cinematic vertical message thread with speed control, transcript, chapters, bookmarks, reactions
- **Recorder** — real camera capture via `getUserMedia` + `MediaRecorder`; record takes and send them into the thread as playable video
- **Archive** — on-device transcript search, bookmarks, highlights
- Floating Liquid Glass bottom tab bar

Open `index.html` in a secure context (HTTPS or localhost) and allow camera/microphone access to test recording.

Built from Google Stitch screens, mounted in a phone viewport with a shared floating tab bar.
